# 📊 GraphL
GraphL is a data visualization app that analyzes COVID-19 statistics across different continents and countries. It provides clear, interactive visualizations to help users explore trends, compare regions, and better understand the global impact of the pandemic

🌍 Whether you're tracking case numbers, recovery rates, or vaccination progress, GraphL offers an intuitive way to explore the data

🛠️ Built for flexibility and clarity, GraphL is designed to make complex datasets easier to navigate and understand
